# 📊 Simple Budget Calculator

A lightweight, interactive command-line **Python utility** designed to help users manage their personal finances. This application tracks monthly net income against essential spending categories to immediately calculate total expenses, net savings, and overall savings rates.

---

## 🛠️ Built With

*   **Python 3.x** - Built exclusively using standard logic suited for safe execution across online sandboxes like Programiz or local terminal environments.

## 📥 How to Run

Copy the code inside `budget.py` and paste it directly into the [Programiz Online Python Compiler](https://programiz.com), or run it locally on your computer:
```bash
python budget.py
```
